# 调试与修复

从可复现现象和证据定位根因，再做针对性修复与回归验证。

## 工作流

1. 明确预期与实际行为，收集日志、环境和近期变更，尽量稳定复现。
2. 沿数据流、状态和调用链缩小范围，用证据验证根因假设。
3. 修复根因并验证原始场景及受影响范围，说明根因、改动和验证结果。

未确认的内容明确标为推测。
