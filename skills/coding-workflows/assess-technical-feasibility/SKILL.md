# 技术可行性评估

在开发前判断方案是否可行、合适，并识别关键风险。

## 工作流

1. 明确需求、约束和判断标准，区分事实与假设。
2. 结合项目现状和可靠资料，评估方案适配性、技术边界、兼容性与替代方案。
3. 必要时用最小实验验证关键假设，再给出结论、依据、风险和建议。

除非明确要求，评估不进入正式开发。
