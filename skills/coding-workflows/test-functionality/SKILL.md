# 自动化测试

围绕用户可观察行为，用少量高价值自动化测试建立交付信心。

## 工作流

1. 明确预期行为、验收范围和主要风险。
2. 选择合适的测试层级，覆盖主路径、边界、错误场景和关键交互。
3. 先做定向验证，再按影响范围扩展；UI 或交互任务在条件允许时使用真实浏览器。

说明测试结果、发现的问题和未覆盖风险。
